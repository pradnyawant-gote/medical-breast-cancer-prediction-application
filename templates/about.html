SonoLab is a website built around the supplied breast ultrasound classification project and its saved Keras model.

THE PROJECT

A practical interface for an existing model.

The training notebook defines a three class image classifier and saves it as model3.h5. This Flask application provides a way to upload an image and review its output without running the notebook.{% if lite_mode %} On Render Free, it runs a smaller LiteRT copy of that model.{% endif %}
